What this shows

Same title, same two lots, same budget split, run fifteen months apart under two different contract folders. Lot 1 (the health lot) found no winner the first time despite eleven bids, and was re-run unchanged — in scope and budget — until it succeeded. This is ordinary procurement behaviour, not an irregularity: TED's own vocabulary has a standard code for exactly this outcome ("closed, no winner selected", justification "other"). The pattern is only visible by holding two notices, fifteen months and several hundred unrelated TED publications apart, in memory at once — which is the kind of fact a persistent machine archive surfaces and a one-at-a-time reader of daily procurement bulletins normally would not.
