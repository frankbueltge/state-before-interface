The envelope

The sentinel queries the TED Search API nightly for these exact phrases (envelope v1, every change is a committed revision with a reason):

  • artificial intelligence (eng)
  • Künstliche Intelligenz (deu)
  • intelligence artificielle (fra)
Why no CPV filter?

V1 keeps the envelope to three exact phrases whose yield was measured on 2026-08-08 (EN ~200-250/yr, DE ~107/yr for DEU buyers, FR unmeasured but structurally expected). No CPV filter: no AI-specific CPV code exists, and filtering by CPV would presuppose the very classification gap this observatory measures. Bycatch is expected and is handled by the gate, not the envelope. Every change to this file is a commit with a reason.
